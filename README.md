## About me

I'm a Software Engineer based in **Faridabad, India**. I build web applications, reusable TypeScript libraries and developer tools, connecting **React/Next.js interfaces** with **Node.js/Express APIs** and database-backed workflows.

My experience spans contract development, open-source maintenance and frontend engineering. I work on API integrations, authentication, automated testing, interactive visualizations and software for electronics design.
## projects

### [Buyora — E-commerce Application](https://github.com/techmannih/ECommerce)

An e-commerce application with storefront screens, cart management, addresses, orders, authentication and checkout.

- React interfaces with **Redux Toolkit** state management and Tailwind CSS.
- Express APIs and Mongoose models, with **JWT authentication**, bcrypt password hashing and **Stripe Checkout**.
- **Stack:** React, Redux Toolkit, Node.js, Express, MongoDB, Mongoose, Tailwind CSS.

### Hack Prodigies — Collaboration Platform

A full-stack application for hackathon discovery and team coordination, built during **Buildspace S5**.

- Event-discovery and team-management workflows backed by REST APIs and MongoDB.
- **Google OAuth 2.0** sign-in and event notifications.
- **Stack:** React, Node.js, Express, MongoDB.

### [Fast Footprint Compare — Footprint Comparison & Validation Tool](https://github.com/tscircuit/fast-footprint-compare)

A developer tool for comparing generated component footprints with supplier data.

- Validates supplier part numbers through an **Express/Zod API**.
- Displays SVG overlays, pad-overlap heatmaps and pin-level position, size and rotation differences.
- **Stack:** TypeScript, React, Express, Vite, Zod, SVG, JLCPCB/EasyEDA data.
